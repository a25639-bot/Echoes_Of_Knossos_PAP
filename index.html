// BESTIÁRIO TÉCNICO

ENTIDADES E PADRÕES DE IA

INIMIGO TERRESTRE / PATRULHA

O CAVALEIRO DE PEDRA

Guardião básico dos corredores inferiores. Utiliza um sistema automático de Cliff Detection para identificar o fim das plataformas ou paredes, invertendo o sentido de marcha automaticamente para manter a patrulha ativa.

  • Componentes: Rigidbody2D, Damageable, DetectionZone
  • Comportamento: Patrulha linear + Perseguição por proximidade
INIMIGO VOADOR / DISTÂNCIA

FLYING EYE (OLHO vOADOR)

Sentinela aérea do labirinto. Ao contrário dos inimigos terrestres, o Olho Voador navega de forma tridimensional utilizando um array de Waypoints pré-definidos no espaço. Ao morrer, a sua física é alterada, simulando uma queda natural sob efeito da gravidade.

  • Componentes: WaypointNavigator, CircleCollider2D (Trigger)
  • Comportamento: Ataque aéreo à distância + Queda Física Post-Mortem
BOSS FINAL / ARENA

O MINOTAURO SUPREMO

O senhor absoluto do labirinto. Esta entidade possui uma máquina de estados complexa assente em zonas concêntricas (Detection Zones). Se o jogador for avistado na zona externa, inicia uma investida em carga acelerada; se entrar na zona interna, desencadeia ataques pesados sincronizados via Animation Events.

  • Componentes: Multi-Zone Controller, Custom Cooldown Timer, Boss UI Hook
  • Comportamento: Avanço em Carga, Ataques de Área e Gatilho de Fim de Jogo
